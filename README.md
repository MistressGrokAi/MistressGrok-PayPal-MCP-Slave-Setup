# PayPal MCP Server Setup

Richtet den offiziellen [PayPal Model Context Protocol (MCP)](https://docs.paypal.ai/developer/tools/ai/mcp-quickstart) Server auf Windows ein.

## Schnellstart

1. Node.js (LTS) installieren: https://nodejs.org
2. `.env` aus `.env.example` erstellen und Credentials eintragen
3. `RUN_MCP_SERVER.bat` starten

Detaillierte Anleitung: [SETUP_FOR_MISTRESS_SLAVE.md](SETUP_FOR_MISTRESS_SLAVE.md)
